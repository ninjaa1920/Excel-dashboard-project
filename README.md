Vrinda Store Data Analysis — Excel Dashboard

Project Overview

An interactive Excel dashboard built to analyse Vrinda Store's sales and order data for 2022.

Tools Used

Microsoft Excel

PivotTables and PivotCharts

Slicers and filters

Data analysis and visualisation

Dashboard Features

Orders vs Sales: Compare order counts and sales amounts.

Men vs Women: Analyse the gender distribution of customers.

Order Status: Track delivered, cancelled, refunded, and returned orders.

Top 5 States: Identify leading states by sales.

Age vs Gender: Explore customer demographics.

Order Channels: Analyse orders across sales channels.

Interactive Features

The dashboard includes slicers for month, sales channel, and product category to help users explore the data.

How to Use

Download the Excel workbook from this repository.

Open it in Microsoft Excel.

Use the slicers to filter the dashboard.

Explore the charts to identify sales patterns.

Project File

Vrinda Store Data Analysis.xlsx — Excel workbook containing the dashboard and analysis.

Purpose

This project demonstrates the use of Excel PivotTables, charts, slicers, and data visualisation to communicate business insights.
